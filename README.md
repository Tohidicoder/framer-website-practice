# Portfolio Website

A modern, responsive portfolio built with React and Tailwind CSS, inspired by the Prive Framer website.

## Features

- Responsive design
- Dark mode and light mode
- Interactive navigation
- Projects showcase
- Blog section
- Smooth hover effects and transitions
- Modern and user-friendly UI

## Technologies Used

- **React** — UI components
- **Tailwind CSS** — Styling and responsive design
- **JavaScript** — Interactivity
- **Vite** — Development and build tool
- **React Router** — Page navigation
- **Git & GitHub** — Version control

## Project Goal

To practice React, Tailwind CSS, responsive design, and modern frontend development by building a professional portfolio website.
